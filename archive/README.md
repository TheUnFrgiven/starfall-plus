# Historical Galactacians versions

`galactacians/` preserves the former browser and Godot projects, including their original design records, names and launch instructions. They are reference versions, not the active Starfall+ game. Their save formats and engine direction differ from the root Unity game.

The exact uncommitted local Godot changes at adoption were separately committed and pushed under `galactacians-local-checkpoint-2026-11-17`; the archive here follows the newer remote main that the Unity branch already included. See [checkpoint recovery](../Docs/CHECKPOINT.md).
