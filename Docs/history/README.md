# Historical Unity records

These are preserved development notes, asset prompts and earlier verification reports from before the Starfall+ baseline. Their old names, paths, snapshots and unresolved states are historical context. They do not override the current [decisions](../DECISIONS.md), [status](../PROJECT_STATUS.md) or [checkpoint](../CHECKPOINT.md).

The art assets they describe are included in the active project. Keep these records for provenance; do not treat an older completion statement as evidence that a later mobile/account flow was verified.
