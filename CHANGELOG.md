# Starfall+ changelog

## 0.1.1 — Android playtest, 18 November 2026

- Add a normal saved-game APK build for ARMv7 and ARM64 phones, landscape orientation, minimum Android 8.0 and the OpenGL ES renderer.
- Clear held touch controls and pause active combat when the mobile app loses focus; save learning and expedition progress when backgrounded.
- Register the native account callback on Unity's generated GameActivity manifest. Google provider setup and real callback-flow verification remain pending.
- Add a padded adaptive Bot launcher icon, Android configuration, callback and interruption checks, plus installation and WhatsApp-sharing instructions. Physical-phone usability and performance remain playtest work.

## 0.1.0 — Base checkpoint, 18 November 2026

- Adopt the pixel-art astronaut/elemental-meteor Unity game as the new active base.
- Move Unity, art, learning and backend source to the repository root; preserve browser/Godot references and previous Unity notes in archives.
- Rename product, GitHub repository, C# source/scene/build identities, dashboard and hosted project labels to Starfall+.
- Preserve Unity GUIDs, player/account IDs and existing save formats. Import known desktop saves without replacing current progress or removing originals.
- Include the existing 14-topic learning flow, worked-example follow-up questions, contextual Bot, collection rewards, six-upgrade screen, enlarged bounded ship and persistent Health/Shield rules.
- Record verified email signup/confirmation and the authenticated parent dashboard. Retain explicit Google, mobile, live multi-account statistics, sync and balance limitations.
- Preserve recovery tags before the rebrand and publish this baseline on main.
